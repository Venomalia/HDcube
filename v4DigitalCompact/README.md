# HDcube 4 Digital Compact
HDcubeDigitalCompact is a model for Png and Jpg images based on the new DAT architecture, it removes most Jpg artifacts up to 50% quality.
It is comparable to 4xHDcubeDigital, but it is significantly faster but not so well suited for images with strong image artifacts.
